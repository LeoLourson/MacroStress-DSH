# mst.data: история значений на известную дату

Пакет `mst.data` загружает месячные временные ряды и сохраняет версии их значений. Временной ряд — значения одного показателя по месяцам; версия значения нужна потому, что источник может опубликовать показатель позже окончания месяца, а затем пересмотреть его. При расчёте на прошлую дату модель должна видеть только публикации, доступные к этой дате.

## Что хранится

Контракт [store.py](<store.py>) задаёт строку `month, value, published, approximate`: месяц показателя, численное значение, дату публикации и признак приблизительной датировки. `SeriesStore.as_of(series, day)` для каждого месяца выбирает последнюю версию, опубликованную не позже `day`, а пересмотр добавляет строку, сохраняя прежнее значение.

При первой загрузке дата оценивается от конца месяца и задержки публикации `lag_days`. Если источник пересматривает историю, первоначально загруженные значения помечаются `approximate`: загружена последняя доступная история, а не подтверждённые архивные публикации. Поэтому фильтр по дате не превращает приблизительно датированный ряд в полноценный архив исторических версий.

```mermaid
flowchart LR
    S[Источник] --> F[Загрузчик]
    F --> V[Новые версии значений]
    V --> C[CSV-хранилище]
    C --> D[Отбор опубликованного на дату]
    D --> P[История для модели]
```

Схема показывает движение одного ряда: загрузчик получает значения, хранилище сохраняет изменения, а модель читает историю через дату публикации.

## Обновление и чтение

Из корня репозитория следующая команда обновляет только ключевую ставку. Команда обращается к сети и записывает новые версии в выбранный рабочий каталог:

```powershell
uv run python -m mst.data update ru.key_rate --workspace workspace
```

Без имени ряда команда обновляет все объявленные источники начиная с января 2012 года. Код выхода `1` означает ошибку хотя бы одного ряда; успешно загруженные ряды остаются сохранёнными. Параметры команды и проверку сертификатов задаёт [cli.py](<cli.py>), а продолжение после ошибки отдельного ряда — [update.py](<update.py>).

Пример чтения уже заполненного хранилища не обращается к сети:

```python
from datetime import date
from pathlib import Path
from mst.data.store import SeriesStore

store = SeriesStore(Path("workspace/series"))
rows = store.as_of("ru.key_rate", date(2026, 10, 29))
```

Дата в примере — дата отбора публикаций; `rows` может быть пустым, если ряд ещё не загружен.

## Где задаются источники

Встроенные источники объявлены в [sources.toml](<sources.toml>), а [sources.py](<sources.py>) объединяет их с пользовательскими объявлениями рабочего каталога. Повтор одного идентификатора в двух наборах отклоняется. Загрузчики находятся в [fred.py](<fred.py>), [cbr.py](<cbr.py>), [cbr_stats.py](<cbr_stats.py>), [moex.py](<moex.py>) и [rosstat.py](<rosstat.py>); [daily.py](<daily.py>) переводит дневные значения в месячные средние или медианы по правилам источника.

Новый ряд существующего вида требует объявления источника, а новый формат источника — загрузчика с `fetch(http, start) -> dict[date, float]` и включения его в `Source`. Сезонность — повторяющееся изменение внутри года — сохраняется в исходной истории; её удаление относится к [подготовке макропанели](<../macro/README.md>). Разбор форматов, пересмотры и сетевые подмены проверяются в [tests/data](<../../../tests/data/README.md>).
