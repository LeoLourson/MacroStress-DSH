# mst.data

Месячные ряды с датой публикации каждого значения и загрузчики, которые их получают.
Как хранятся версии значений, описано в
[../../../docs/architecture.md](../../../docs/architecture.md#ряды-и-даты-публикации).

```powershell
python -m mst.data update [SERIES ...] --workspace DIR
```

Команда загружает с января 2012 года все ряды `sources.toml` (или только названные) и
добавляет новые версии в `<workspace>/series/<id>.csv`. Код выхода 1 — какой-то ряд не
загрузился; остальные при этом сохранены. Запросы уходят только к источникам из
`sources.toml`.

| Файл | Что делает |
|---|---|
| `sources.toml` | Откуда берётся каждый ряд: таблица на id с `loader`, `lag_days` (дней от конца месяца до публикации), `revised` (пересматривает ли источник значения) и полями загрузчика |
| `sources.py` | Чтение `sources.toml` вместе с `<workspace>/sources.toml`, поиск и добавление источника (инструмент `series`) |
| `store.py` | `SeriesStore`: один CSV на ряд, `as_of(day)` — значения, известные на дату; `new_versions` решает, какие строки добавить после загрузки |
| `update.py` | Цикл загрузки: ошибка одного ряда не останавливает остальные |
| `cli.py`, `__main__.py` | Команда `python -m mst.data`; HTTP-клиент с проверкой сертификатов |
| `release.py` | Общие поля источника: `lag_days`, `revised` |
| `daily.py` | Дневные значения в месячные: среднее, медиана, среднее по календарным дням для ступенчатых ставок |
| `fred.py` | FRED: Brent, ставка ФРС, UST 10Y, VIX; ключ из `FRED_API_KEY` |
| `cbr.py` | Банк России: ключевая ставка и RUONIA (SOAP), официальные курсы, бескупонная кривая ОФЗ |
| `cbr_stats.py` | Банковская статистика ЦБ: кредит, ставка ипотеки, доля просрочки по отраслям; новые месяцы из сервиса открытых данных, старые из архивных Excel-таблиц |
| `moex.py` | Московская биржа ISS: закрытия индексов и акций (со сплитами), спреды индексов облигаций и отдельных выпусков к кривой ОФЗ |
| `rosstat.py` | Росстат: месячные таблицы, «Краткосрочные экономические показатели», цены жилья по территориям; приросты к прошлому месяцу собираются в уровень |
| `mintsifry-roots.pem` | Корневые сертификаты Минцифры; подключаются только для `rosstat.gov.ru` |

Новый ряд существующего вида — новая таблица в `sources.toml`. Инструмент
`series(action="add")` пишет её не сюда, а в `<workspace>/sources.toml`: этот файл читается поверх
встроенного, и id в двух файлах не должны повторяться.
Новый вид источника — класс с полем `loader: Literal[...]` и методом
`fetch(http, start) -> dict[date, float]`, добавленный в объединение `Source` в
`sources.py`. Ряды Росстата хранятся без сезонной корректировки; её снимает `mst.macro`.
