# mst.drivers

Драйверы раздела 6 [формализации](../../../docs/scenario-formalization.md): величины
объектов (цена акции, спред выпуска, доля просрочки отрасли, цена жилья региона), их
каталоги, иерархические сателлитные модели от макропеременных, проверка вне выборки и пути
драйверов под симуляцией макромодели.

```powershell
python -m mst.drivers update [QUANTITY ...] --store DIR --drivers FILE
python -m mst.drivers estimate --macro SHA256 --store DIR --models DIR --drivers FILE
python -m mst.drivers check --macro SHA256 --store DIR --models DIR --drivers FILE
```

`update` запускает каталог каждой величины, загружает ряды найденных объектов и пишет
драйверы с историей в `--drivers` (`workspace/drivers/catalog.json`). `estimate` оценивает
сателлиты на панели макроверсии `--macro` по данным, известным на её дату, проверяет каждый
драйвер и пишет версию в `<models>/satellites/<sha256>/`; `check` делает то же без записи.
Обе печатают таблицу проверки. Запускать только через `python -m`: `__main__.py` ставит
`OPENBLAS_NUM_THREADS=1`, без этого оценка идёт часами.

| Файл | Что делает |
|---|---|
| `registry.toml`, `registry.py` | Величины: единица, преобразование (`identity`, `log100`, `logit`), регрессоры и признаки $\max(0, y-c)$, лаги, `span`, каталог. Объекты и драйверы из каталога добавляются при загрузке; `match` и `resolve` находят драйвер позиции по коду |
| `objects.py` | Контракты объекта (класс, родитель, коды) и драйвера `<величина>:<объект>`; ряд драйвера — `drv.<величина>.<объект>` |
| `catalogs/` | Каталоги объектов по источникам, см. [catalogs/README.md](catalogs/README.md) |
| `update.py` | Каталог → загрузка рядов через `mst.data` → `catalog.json`. Упавший каталог сохраняет прошлую запись величины |
| `spec.toml`, `spec.py` | Спецификация оценки: априорные отклонения, предел $\rho$, длина проверки и горизонт прогноза, сэмплер |
| `estimate.py` | Иерархический сэмплер Гиббса по дереву объектов, розыгрыш ненаблюдаемых месяцев, корреляция остатков |
| `check.py` | Проверка вне выборки против авторегрессии без макропеременных; кто обслуживается и почему нет |
| `version.py` | Версия сателлитов: сборка, сохранение, загрузка с проверкой хеша, список и описание |
| `simulate.py` | Пути драйверов на путях макромодели, с надбавками сценария и пометками |
| `cli.py`, `__main__.py` | Команда `python -m mst.drivers` |

Новый объект существующего источника появляется сам при следующем `update`. Новая
величина — таблица `[[quantities]]` в `registry.toml`; если у её источника нет каталога,
нужен новый класс в `catalogs/`.

Тесты — [../../../tests/drivers](../../../tests/drivers/README.md).
