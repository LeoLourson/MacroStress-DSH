# Каталоги объектов для драйверов

Пакет `mst.drivers.catalogs` находит у источника объекты заданной величины и сообщает, как загрузить их историю. Например, для величины «цена акции» каталог находит акции и их отраслевые группы; сами цены затем загружает [mst.data](<../../data/README.md>). Каталог отвечает за состав объектов, а не за статистическую модель их будущего.

## Контракт обнаружения

Базовый класс `Catalog` и результат `Discovery` определены в [base.py](<base.py>). Метод `discover(http) -> Discovery` возвращает объекты, источники рядов по объектам и перечень пропущенного с причинами. Родитель должен находиться в списке объектов раньше потомка, чтобы дерево можно было построить за один проход.

## Поддерживаемые виды каталогов

| Объявление `loader` | Реализация | Что обнаруживает |
| --- | --- | --- |
| `moex_shares` | [moex.py](<moex.py>) | Акции и отраслевые индексы Московской биржи |
| `moex_bonds` | [moex.py](<moex.py>) | Выпуски облигаций, эмитентов и группы индексов |
| `cbr_activities` | [cbr.py](<cbr.py>) | Отрасли банковской статистики Банка России с кодами ОКВЭД |
| `rosstat_regions` | [rosstat.py](<rosstat.py>) | Страну, округа и регионы из таблиц цен жилья Росстата |

ОКВЭД — классификатор видов экономической деятельности; код помогает сопоставить позицию с отраслевым объектом. Дерево групп нужно модели, которая может использовать параметры более общего объекта, когда собственной истории недостаточно; правила такого заимствования принадлежат модели.

Величина объявляет каталог в [реестре драйверов](<../registry.toml>): поле `loader` выбирает загрузчик, а `lag_days` и `revised` задают условия публикации. Новый объект существующего источника появляется при следующем обновлении, если источник возвращает его в используемой выборке. Для нового формата источника нужен подкласс `Catalog` и включение в объединение `CatalogSource` в [__init__.py](<__init__.py>); проверка соответствия типов не заменяет теста разбора реального формата.

Рабочий пример вызова без написания нового каталога — команда обновления `share_price` в [руководстве mst.drivers](<../README.md>). Структура дерева и разбор ответов с подменённой сетью проверяются в [test_catalogs.py](<../../../../tests/drivers/test_catalogs.py>).
