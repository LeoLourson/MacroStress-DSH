# mst.drivers.catalogs

Каталог находит у источника все объекты величины и для каждого объявляет источник ряда из
`mst.data`, поэтому ряды драйверов загружаются и хранятся так же, как макроряды. Каталог
объявляется в `../registry.toml` под своей величиной таблицей с `loader` и условиями
публикации (`lag_days`, `revised`). Новый объект существующего источника правки кода не
требует.

| Файл | `loader` | Что находит |
|---|---|---|
| `base.py` | — | Базовый `Catalog`, результат `Discovery` (объекты, источники рядов, пропущенное с причиной), имена объектов `slug` и `name` |
| `moex.py` | `moex_shares` | Обыкновенные и привилегированные акции режима торгов; каждая под отраслевым индексом MOEX, в который входит. Режимы до T+2 и сплиты берутся из ISS |
| `moex.py` | `moex_bonds` | Выпуски из индексов корпоративных облигаций (по индексу на рейтинговую группу), под эмитентом, эмитент — под группой первого выпуска |
| `cbr.py` | `cbr_activities` | Отрасли таблицы ЦБ 01_02_A; уровень — по отступу подписи, корень «ВСЕГО», коды ОКВЭД 2 по подписи |
| `rosstat.py` | `rosstat_regions` | Россия (643), федеральные округа и субъекты по кодам ОКАТО из таблиц цен жилья; объекты `okato_<код>` общие для первичного и вторичного рынка |

Новый источник — подкласс `Catalog` с полем `loader: Literal[...]` и методом
`discover(http) -> Discovery`, добавленный в объединение `CatalogSource` в `__init__.py`.
Объекты в `Discovery.objects` идут после своего родителя.
