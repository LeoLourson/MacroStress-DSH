# mst.plugins.hier

Референсная сателлитная модель уровней выше нуля (раздел 6.2 формализации): регрессия каждого
драйвера на своё прошлое и макровходы `x_t`, иерархия параметров по дереву объектов
(Гиббс: объект — вокруг родителя, класс — вокруг среднего), розыгрыш ненаблюдаемых месяцев,
проверка вне выборки против авторегрессии без макропеременных.

Величины из `spec.differences` оцениваются на месячных изменениях:
$\Delta d_t = c + \rho\,\Delta d_{t-1} + \beta_0^\top \Delta x_t + \beta_1^\top \Delta x_{t-1} + e_t$.
У трендовой цены уровень, к которому тянет регрессия уровней
на трендовые регрессоры, ложный; в разностях коэффициенты — эластичности, `c` — месячный
дрейф, долгосрочный уровень исчезает. Симуляция копит изменения от последнего известного
уровня, воздействия ложатся на уровень после накопления; полоса обучения и проверка вне
выборки остаются в уровнях, так что флаг выхода за полосу и вердикт проверки сравнимы с
величинами в уровнях. `share_price` идёт в разностях; жильё (квартальный `span`), облигации
и просрочка (стационарные) — в уровнях.

Пакет подключается как любой модельный плагин: `plugin = Plugin(..., satellites=(MODEL,))`
с моделью `hier.gibbs`, обслуживающей величины реестра драйверов. Величину могут заявить
несколько сателлитных моделей (плагин в разработке рядом с установленным); тогда модель,
которая её оценивает, называется явно — `--model ВЕЛИЧИНА=МОДЕЛЬ` в
`python -m mst.models estimate-satellites`; назначение без имени неоднозначно и отклоняется.

| Файл | Что делает |
|---|---|
| `plugin.py` | Объявление плагина: одна сателлитная модель `hier.gibbs` |
| `model.py` | Адаптер к `mst.model_sdk`: estimate/load/simulate; часть версии несёт объявление величины, так что загрузка не нуждается в реестре |
| `estimate.py` | Гиббс по дереву объектов, шкалирование столбцов, стационарность `rho`, остатки на апостериорном среднем |
| `check.py` | Проверка вне выборки: holdout, горизонт reach, RMSE против AR(1) без макро |
| `simulate.py` | Пути драйверов на путях макромодели: старт с последнего известного значения (в разностях — накопление изменений от него), дорисовка месяцев до `t=0`, совместный шум по корреляции версии, воздействия; если платформа передала `shocks` (бандл из нескольких моделей), берутся они, а поток модели остаётся за номером апостериорного розыгрыша и независимым шумом |
| `spec.py`, `spec.toml` | Спецификация: априорные отклонения, разброс постоянной по величинам (`constant_spreads`), `rho_max`, holdout/reach, `differences` (величины в разностях), сэмплер |

Тесты — `tests/hier`. Подготовка данных (история величины на панели, `x` из путей,
корреляция остатков) осталась в ядре — `mst.drivers.history`; сборка версии из частей
нескольких моделей — `mst.drivers.bundle`. Ещё одна сателлитная модель — отдельный пакет,
который обслуживает свои величины.
