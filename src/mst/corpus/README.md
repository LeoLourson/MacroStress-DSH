# mst.corpus

Корпус источников, по которому собираются сценарии: методики регуляторов, наборы
сценариев, работы о трансмиссии и карточки исторических эпизодов.

Перенесён только `manifest.py` — модель файла `corpus/manifest.json`: источники и их
документы, откуда скачивать оригинал (`url` или страница со ссылкой), статус текста
(`planned`, `raw`, `ready`), эпизоды с первым месяцем и ряды данных. Манифест уже нужен
бэктесту макромодели: даты расчёта эпизодов берутся из него
(`<workspace>/corpus/manifest.json`).

Загрузка, конвертация в Markdown, нарезка на фрагменты, индекс, поиск с отсечкой по дате и
инструмент MCP `corpus` — шаг 6 [плана](../../../PLAN.md). В docstring манифеста ещё стоит
имя команды старого проекта `msa-corpus convert`; в новом она будет
`python -m mst.corpus convert`.
