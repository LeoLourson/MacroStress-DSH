# mst.metrics

Каркас качества раздела 5 [схемы](../../../docs/system-scheme.md): как система судит о версиях
моделей на исторических эпизодах.

```powershell
python -m mst.metrics backtest [MODEL_ID] --as-of DATE --store DIR --models DIR --corpus FILE \
  [--drivers FILE] [--satellites] [--only ID ...] [--details FILE]
```

| Файл | Что делает |
|---|---|
| `cells.py` | Ячейка $(e,t,q)$: факт, розыгрыши, случайное блуждание, базовый расчёт и наивный прогноз; CRPS (точная оценка по рангам), mid-PIT $\hat F(y)$, полоса, $\sigma_q(t)$, размах истории, баллы ячейки, бутстрэп по эпизодам |
| `baselines.py` | Эталоны: случайное блуждание с дрейфом и наивный годовой прогноз; правила допуска (область значений, размах истории); вероятность ограничения в базовом расчёте |
| `episodes.py`, `episodes.toml` | Эпизоды: связанная переменная, движущие шоки, окно, исключения; дата расчёта — день до начала |
| `backtest.py` | Раннер: версия макромодели на день до эпизода (кэш по состоянию данных и конфигурации модели), сценарий из случившегося, ячейки по несвязанным переменным и (с `--satellites`) драйверам, гейты, интервалы, метаданные воспроизводимости, таблицы и полный отчёт |
| `cli.py`, `__main__.py` | Команда `python -m mst.metrics` |

## Что именно измеряется

- **Ячейка** — эпизод, месяц горизонта, величина. Связанная сценарием ячейка отчитывается, но
  не оценивается: условный прогноз в ней совпадает с фактом.
- **CRPS/$\sigma_q(t)$** — CRPS, делённый на типичное движение величины за $t$ месяцев. И
  $\sigma_q(t)$, и размах истории берутся из истории, известной **на дату расчёта этого
  эпизода**; поэтому результат не зависит от `--only` и от того, какие эпизоды загрузились.
- **PIT** — mid-PIT $(below + tied/2)/R$: для непрерывных розыгрышей это $\hat F(y)$; у прогноза
  с атомом в факте он не равномерен, поэтому целевые доли корзин 0,05/0,45/0,45/0,05 — только
  для непрерывного прогноза.
- **Случайное блуждание с дрейфом** — отдельный эталон на тех же ячейках и с тем же числом
  розыгрышей, из панели эпизода. **Базовый расчёт** — безусловный прогон той же модели; это
  другая величина, и в отчёте она стоит отдельным столбцом `base run/sigma`. Модель не выдаётся
  за случайное блуждание.
- **Наивный прогноз** целевого показателя на месяц $T+t$ — значение годом ранее, $y[T+t-12]$,
  плюс $t$ месячных дрейфов; для $t>12$ и пропусков действует последнее известное значение не
  позже нужного месяца.
- **Допуск** — два правила, каждое со своей долей **по всем оценённым ячейкам**: полоса внутри
  области значений величины и ширина полосы не больше размаха истории. Версия проходит, если
  каждая доля меньше 5 %; объединение правил и разбиение по величинам в приговор не идут (они
  отчитываются справкой).
- **$\pi_c$** — доля путей базового расчёта, выполняющих ограничение; гейт $\pi_c>1\%$. У
  эпизода, восстановленного по факту, ограничения точечные ($low=high$), и непрерывный розыгрыш
  попадает в точку с вероятностью ноль: там $\pi_c$ помечается как **неприменимая** и из гейта
  исключается, а не печатается нулём. Для интервальных ограничений гейт настоящий.
- **Интервалы** — 95 % бутстрэп по эпизодам, 1000 повторений, `seed` из `episodes.toml`.
  Пересэмплируется та же статистика, что в отчёте (среднее по ячейкам, а не среднее средних по
  эпизодам); у разницы «модель минус случайное блуждание» свой парный интервал.

## Чего в каркасе нет

Приговор версии по разделу 5 не выносится: нет равновесного среднего по величинам и разреза
по уровням и горизонтам, нет четырёхшагового правила 2 SE, нет Acerbi–Székely $Z$ и бэктеста
ES (нужны реализованные потери портфеля), нет wild cluster bootstrap с весами Уэбба (мало
кластеров), нет деления эпизодов на половины настройки и проверки, нет разделения ошибки
Монте-Карло и ошибки выборки. Отчёт не обещает их: список лежит в `meta["missing"]` файла
`--details`, а столбцы и docstring говорят только о том, что посчитано. Покрытие и
резкость — справка, а не цель.

Версии эпизодов пишутся в `<models>/backtest/`; ключ кэша включает данные на дату расчёта,
конфигурацию пакета модели (`spec.toml`, `signs.toml` и код), реестр макро-переменных и версию
model SDK, поэтому правка конфигурации не переиспользует старую версию.

Тесты — [../../../tests/metrics](../../../tests/metrics/).
