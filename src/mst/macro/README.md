# mst.macro: общие показатели экономики и их история

Пакет `mst.macro` задаёт макропеременные, собирает их историю на дату расчёта и хранит версии макромоделей. Макропеременная — показатель экономики в целом, например валютный курс или процентная ставка. Макромодель строит совместное распределение будущих показателей; её математический метод принадлежит подключаемому плагину, поэтому пакет `mst.macro` не выбирает единственную экономическую модель.

## Реестр, панель и версия

[Реестр registry.toml](<registry.toml>) задаёт идентификатор, единицу, источник и преобразование каждой переменной. Префиксы `gl.` и `ru.` различают глобальные и российские показатели, но сами по себе не доказывают направление экономической связи: ограничения конкретной модели описываются в её документации.

`identity` сохраняет исходную единицу, а `log100` переводит положительное значение в сто натуральных логарифмов. Логарифмическая шкала используется внутри моделей; ставка в процентах и логарифм цены не взаимозаменяемы. Правила прямого и обратного перевода заданы в [registry.py](<registry.py>).

Панель — прямоугольная таблица «месяц × переменная», которую строит [panel.py](<panel.py>) из публикаций, известных на заданную дату. Глобальные переменные располагаются первыми; неизвестное значение остаётся `NaN`, то есть пропуском, а не нулём. Для выбранных переменных панель удаляет повторяющийся календарный профиль, рассчитанный только по доступной истории.

```mermaid
flowchart LR
    H[Версии рядов] --> P[Панель на дату]
    R[Реестр и шкалы] --> P
    P --> M[Плагин макромодели]
    M --> V[Сохранённая версия]
    V --> S[Пути при сценарии]
```

Схема разделяет подготовку данных и оценку модели: одинаковая история может использоваться разными плагинами, а сохранённая версия фиксирует результат одной оценки.

[Модуль version.py](<version.py>) сохраняет панель, дату, идентификаторы переменных, название модели и остальные метаданные с массивами. Загрузка передаётся модели, названной в `meta["model"]`; если модель не установлена, версия не читается. Хеш содержимого защищает от незаметного изменения сохранённых массивов, но совместимый код плагина всё равно нужен для их интерпретации.

## Операции

Оценкой и перечнем версий управляет [mst.models](<../models/README.md>). Из корня репозитория можно сначала узнать идентификаторы моделей, затем оценить выбранную на уже загруженной истории:

```powershell
uv run python -m mst.models catalog
uv run python -m mst.models estimate-macro rw.joint --as-of 2026-10-29 --store workspace/series --models workspace/models
uv run python -m mst.models list --models workspace/models
```

Дата в примере задаёт доступность публикаций, а не начало прогнозного горизонта. Начальный месяц путей — последний месяц панели, который может быть раньше даты расчёта из-за задержки публикаций.

Функция `base` в [version.py](<version.py>) возвращает квантили пустого сценария в шкале модели. Квантиль P50 — медиана, а P5 и P95 ограничивают центральные 90 % распределения; при чтении результата нужно различать модельную шкалу и исходные единицы прогноза. Контракт панели и сохранения проверяется в [tests/macro](<../../../tests/macro/README.md>), а свойства конкретной макромодели — в её собственных тестах, например [tests/bvar](<../../../tests/bvar/README.md>).
