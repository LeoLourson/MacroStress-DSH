# mst.macro

Контракт уровня 0 [формализации](../../../docs/scenario-formalization.md): реестр
макропеременных, сборка панели на дату расчёта и хранилище версий макромодели. Сама
макромодель — подключаемый плагин: BVAR со стохастической волатильностью живёт в
[mst.plugins.bvar](../plugins/bvar/README.md), ещё одна модель — отдельный пакет со своим
`model_id`, подключаемый через реестр `mst.plugins` (entry points, `MST_PLUGINS_PATH` или
пакет в пространстве имён), см. [docs/plugins.md](../../../docs/plugins.md).

```powershell
python -m mst.models estimate-macro bvar.sv --as-of 2026-10-29 --store DIR --models DIR
python -m mst.models list --models DIR
```

| Файл | Что делает |
|---|---|
| `registry.toml`, `registry.py` | Реестр: 23 переменные с преобразованием $g$, блоки `gl.`/`ru.`; именованные шоки принадлежат макромодели, которая ими идентифицируется |
| `panel.py` | Панель: ряды на дату в шкале модели на сетке месяцев, глобальный блок первым, снятие сезонности, пропуски как NaN |
| `version.py` | Версии макромодели поверх `mst.versions`: проверка обязательных ключей, сохранение, загрузка плагином, который оценил (`meta["model"]`), панель версии, список и описание |

Правка `registry.toml` действует только на новые версии: версия хранит и реестр, и
спецификацию, с которой оценена. Оценка детерминирована сидом, записанным в спецификации.

Тесты — [../../../tests/macro](../../../tests/macro/README.md); тесты BVAR —
[../../../tests/bvar](../../../tests/bvar/).
