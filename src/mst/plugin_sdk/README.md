# mst.plugin_sdk: договор с моделью позиции

Пакет `mst.plugin_sdk` задаёт входы и результат модели, которая переводит пути показателей в стоимость одной позиции портфеля. Комплект средств разработки, или SDK, отделяет экономическую формулу от загрузки истории и управления расчётом. Модель получает готовые совместные пути и должна вернуть изменение стоимости на каждом пути, чтобы платформа могла сложить позиции без потери их зависимости.

## Ответственность модели

Контракт [model.py](<model.py>) состоит из последовательных методов:

| Метод | Что получает и возвращает |
| --- | --- |
| `requirements(position, options)` | По типу позиции и условиям расчёта объявляет нужные драйверы и макропеременные |
| `validate(prepared)` | Проверяет подготовленные входы и возвращает диагностики с уровнем `warning` или `error` |
| `calculate(prepared, context)` | Читает общие пути и возвращает `CalculationResult` |

Позиция `Position` содержит `type`, положительный `notional`, валюту, коды объекта и специальные условия `terms`. Денежный номинал задан в миллионах валюты позиции; `PreparedInputs.value_current` — текущая стоимость в миллионах базовой валюты. Драйвер, например `share_price:sber`, связывает измеряемую величину с объектом; `DriverRequirement` позволяет запросить его по объекту либо по кодам позиции.

Модель обязана быть чистым расчётом: без чтения файлов, сети и собственного розыгрыша случайных чисел. Правило нужно для повторяемости и совместности результатов; SDK не создаёт операционную песочницу, которая технически запрещает стороннему Python-коду доступ к файлам.

## Что означают пути

[Протокол Paths](<paths.py>) возвращает массив формы `(R, H + 1)`, где `R` — число путей, `H` — горизонт в месяцах, а столбец `0` — последний месяц истории. Макропеременные и драйверы приходят в исходных единицах: ставка — в процентах, доля — в долях единицы, цена — в своей денежной единице. Преобразования внутренних моделей в расчёт позиции не переносятся.

Самодостаточный пример показывает разницу отношения и изменения:

```python
import numpy as np
from mst.plugin_sdk.paths import FixedPaths, change, relative

paths = FixedPaths(drivers={
    "share_price:demo": np.array([[100.0, 110.0], [100.0, 90.0]])
})
prices = paths.driver("share_price:demo")
assert np.allclose(relative(prices)[:, -1], [1.1, 0.9])
assert np.allclose(change(prices)[:, -1], [10.0, -10.0])
```

Числа примера — учебные входы: отношение цены к началу отличается от изменения цены в денежных единицах. `relative` отклоняет нулевой начальный уровень, поскольку отношение к нулю не определено.

## Результат и служебные функции

[Модуль results.py](<results.py>) задаёт `CalculationResult`, массив `value_change`, метрики `MetricValue` и квантили `Quantiles`. P50 — медиана, а P5 и P95 ограничивают центральные 90 % значений; для потери, у которой большее значение хуже, добавляется ES95 — средняя потеря в худших 5 % распределения. Положительное `value_change` означает рост стоимости, поэтому потеря имеет противоположный знак.

`envelope` собирает результат и переносит пометки драйверов: использование параметров родителя, приблизительные данные, вмешательство и выход за диапазон обучения. Если модель обходит `envelope`, ответственность за сохранение необходимых пометок остаётся у автора модели. [Модуль fx.py](<fx.py>) рассчитывает валютный пересчёт из общих макропутей, а не из отдельной загрузки курса.

Объявление пакета `Plugin` и демонстрационный случай `DemoCase` находятся в [plugin.py](<plugin.py>). Проверка `check_plugin` в [testing.py](<testing.py>) вызывает модель через диспетчер платформы и проверяет контракт и повторяемость демонстрации. Совместимость задаётся полем `sdk`; действующая версия `1.1.0` определена в [version.py](<version.py>).

Для полноценного расширения используйте [руководство по плагинам](<../../../docs/howto/plugins.md>), а для проверки границы модели — [tests/plugins](<../../../tests/plugins/README.md>) и [tests/engine](<../../../tests/engine/README.md>). Совпадение с контрактом подтверждает форму взаимодействия, но не точность экономической формулы.
