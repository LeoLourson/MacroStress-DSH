# mst.engine

Расчёт позиций без ветвления по типу актива: модели приходят из реестра `mst.plugins`, а
движок спрашивает каталог, готовит входы и проверяет, что модель вернула. Контракты модели и
путей — [platform.md](../../../docs/platform.md).

| Файл | Что делает |
|---|---|
| `model_catalog.py` | `Catalog`: модели по id и модель, обслуживающая тип актива; реестр читается лениво, при первом обращении |
| `dispatch.py` | `prepare` — `terms` по схеме модели, её `requirements`, сверка макропеременных с путями, разрешение драйверов в каталоге сателлитной версии, `validate`; `calculate` — расчёт и сверка результата с объявлением; `not_run` — позиция со статусом `invalid` и причиной |
| `run.py` | `run` — все позиции на одном наборе путей; `Batch` с результатами в порядке позиций и худшим статусом |
| `status.py` | Порядок статусов `ok` < `needs_review` < `invalid` и худший из набора |

Позиция остаётся в прогоне с причиной отказа, если типа актива нет в каталоге или его
обслуживают две модели, если `terms` не проходят схему, если объявленной макропеременной нет
в путях, если для требуемой величины нет обслуживаемого драйвера или модель нарушила своё
объявление. Исключение внутри модели даёт `invalid` с кодом `model_error:<Тип>` и не
останавливает остальные позиции. `invalid` не входит в арифметику портфеля; `needs_review`
входит, и отчёт это раскрывает.

Тесты — [../../../tests/engine](../../../tests/engine/README.md).
