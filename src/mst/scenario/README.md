# mst.scenario

Сценарий стресс-теста $(N, C, D, O)$ из раздела 3
[формализации](../../../docs/concept/scenario-formalization.md): нарратив $N$, ограничения $C$ на
пути макропеременных, движущие шоки $D$ и надбавки $O$ к драйверам. Сценарий — файл
`workspace/scenarios/<id>.json`; прогон строит из него пути $R \times (H+1)$.

| Файл | Что делает |
|---|---|
| `contracts.py` | `Scenario`, `Constraint` (веса, границы в шкале $y=g(X)$), `Term`, `Impact` (воздействие $o_l$: макропеременная или драйвер, месяцы, $\Delta$); месяц за горизонтом, `low > high`, повтор переменной в месяце — отказ |
| `spec.py` | Файл `scenarios/<id>.json`: тот же `Scenario` плюс хеши макроверсии и сателлитов, на которых он считается |
| `build.py` | `build`: условный прогноз макромоделью-плагином (план $C, D$), воздействия на макропеременные входят в путь до сателлитов, затем бандл `mst.drivers` симулирует драйверы их моделями с воздействиями на те же розыгрышах; жёсткость $\delta$ — метод `severity` модели. `validate` называет каждую невыполнимую связку, воздействия на неизвестные переменные и не обслуживаемые драйверы |
| `tool.py` | Операции инструмента `scenario`: `list`, `get`, `save`, `validate` |

Границы ограничений — в шкале модели $y=g(X)$: для ставки проценты, для курса $100\ln X$.
Имена переменных сверяет реестр `mst.macro.registry`, имена шоков — макроверсия ($J$ — свойство модели).

Пути (`Paths` в `build.py`) — $R$ розыгрышей на $H$ месяцев: макропеременные и драйверы в
исходных единицах, пометки путей драйверов (воздействие, параметры сверху, приблизительные
данные, выход за диапазон обучения) и жёсткость сценария. Модели позиций читают их одной и
той же формой.

Проверки `validate`:

- неизвестная переменная или шок — по реестру `src/mst/macro/registry.toml`;
- связанность ограничений: строка, которую движущие шоки не могут сдвинуть сами, — отказ с
  номером ограничения;
- воздействие на переменную, которой нет в макроверсии, и на драйвер, который бандл не обслуживает, — с причиной отказа;
- сателлиты другой макроверсии — с обоими месяцами;
- фрагмент корпуса, указанный в сценарии, вышел позже даты расчёта, — если индекс корпуса
  собран.

Тесты — [../../../tests/scenario](../../../tests/scenario/).
