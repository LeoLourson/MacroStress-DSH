# mst.scenario

Сценарий стресс-теста $s=(N,I,\mathcal A)$ из раздела 3
[канона](../../../docs/concept/formalization.md): нарратив $N$ с источниками, вмешательства $I$
(величина, календарные месяцы, установка или сдвиг, значения в единицах величины) и наблюдения
$\mathcal A$ (полоса на величину, границы на среднее, вероятность). Версий моделей, горизонта и
числа путей в файле нет: их называет запрос расчёта, поэтому один файл считается на любой
системе моделей. Сценарий — файл `workspace/scenarios/<id>.json`; расчёт строит из него пути
$R\times(H+1)$.

| Файл | Что делает |
|---|---|
| `contracts.py` | `Scenario` (`narrative`, `sources`, `interventions`, `observations`, `approved_by`); `Intervention` (`quantity`, `months` в формате `YYYY-MM`, `kind` — `set` или `shift`, `values` по числу месяцев, `unit` — `level`, `change` или `percent`, `reason`, `basis`); `Term` (величина, месяц, вес); `Constraint` (интервал `low < high` или точка `value`), `Expectation`, `ProbabilityCondition` (`low`, `high`, `at_least`) — `Observation`; месяц не по шаблону, повтор месяца, случайный закон значения и пара (величина, месяц) в двух вмешательствах — отказ |
| `spec.py` | `Spec = Scenario`: файл `scenarios/<id>.json` без версий и без настроек расчёта |
| `translate.py` | `month_index` и `calendar_month` (номер месяца от последнего месяца панели, не от даты расчёта), `to_scale` и `shift_to_scale` (`level` — уровень величины, `change` — изменение от последнего известного значения, `percent` — доля для величин в `log100`), `observation_bounds`, `observations_of`, `observation_constraints`, `plan_of` → `ScenarioPlan`; модель не читает |
| `context.py` | `TranslationData` из панели макроверсии и историй сателлитов: начало календаря, шкалы величин, последние известные значения |
| `build.py` | `build` — пути: макромодель под наблюдениями, вмешательства в форме по умолчанию ставятся после розыгрыша (`apply_default`), а модель со структурной формой исполняет их сама; наклон под наблюдения на средние (`overlay`), сателлиты по уровням, наблюдения на драйверы — перевзвешивание внутри групп при `inner` не меньше 2, цена $\mathrm{dist}(s)$. `dist_of` считает только цену, `validate` возвращает `problems`, `labels` и `warnings` |
| `overlay.py` | `solve_lambda`: выпуклая двойственная задача наклона $e^{\lambda'f}$ (L-BFGS-B, знаковые границы односторонних наблюдений) — веса внутри групп $R$, цена, эффективный размер, достижимость; `resample` — систематический ресэмплинг внутри групп |
| `legacy.py` | `read_legacy`: читает файл прежнего формата (воздействия становятся сдвигами, условия — наблюдениями), а названные причины и событие-режим записывает строкой в нарратив; файлов не пишет |
| `migrate.py` | `migrate`: переписывает каталог старых файлов в новом виде и, если были названы причины, оставляет список `<каталог>-migration-causes.txt`; `python -m mst.scenario migrate DIR --workspace DIR` |
| `reverse.py` | Обратная задача канона (раздел 6): `Family` с фиксированными версиями и вмешательствами, `sup_rho` под ценой $\kappa$ и `inf_dist` над уровнем $L^*$; `python -m mst.scenario reverse` |
| `tool.py` | Операции инструмента `scenario`: `list`, `get`, `save`, `validate`, `reverse` |

Числа записаны в единицах величины и календарных месяцах, а не в шкале модели и не номерами
месяцев. `level` — значение величины, `change` — изменение от последнего известного значения в
тех же единицах, `percent` — относительное изменение в процентах для величин, которые реестр
держит в `log100`. Перевод в шкалу реестра и в номера месяцев горизонта делает `translate` от
последнего месяца панели модели. Значение вмешательства может нести свой закон: `uniform`
разыгрывает число на группу путей, `with_probability` включает записанное значение с заданной
вероятностью. Законы разыгрываются на отдельном потоке случайных чисел от seed, поэтому
добавленное наблюдение не сдвигает ни одного разыгранного числа, а цена сценария усредняется
по группам.

Пути (`Paths` в `build.py`) — $R$ розыгрышей на $H$ месяцев: макропеременные и драйверы в
исходных единицах, пометки путей драйверов (вмешательство, параметры сверху, приблизительные
данные, выход за диапазон обучения), цена сценария с разложением по уровням, эффективный размер
наклона и проверки наложенного. У сценария из одних вмешательств наблюдений нет, поэтому цена
равна нулю и записана нулём. Модели позиций читают пути одной и той же формой.

Проверки `validate`:

- неизвестная величина — по реестру макропеременных и величинам бандла сателлитов;
- месяц до последнего месяца панели или за горизонтом проверки — с названием месяца;
- наблюдение, которое не переводится в одну шкалу: макропеременные вместе с драйверами, разные
  шкалы, среднее на величине в `log100`, веса не той суммы;
- `percent` на величине не в шкале `log100` и отсутствие последнего известного значения, от
  которого считается изменение;
- повтор пары (величина, месяц) и случайный закон значения — отказ уже при `save`;
- сателлиты другой макроверсии — с обоими хешами;
- фрагмент корпуса, указанный в сценарии, вышел позже даты расчёта, — если индекс корпуса
  собран;
- отсутствие утверждения; предупреждения — нет источников, все элементы на допущениях, нет ни
  наблюдений, ни вмешательств и поэтому это базовый $s_0$.
