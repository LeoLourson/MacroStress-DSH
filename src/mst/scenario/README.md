# mst.scenario

Сценарий стресс-теста $(N, C, D, O)$ из раздела 3
[формализации](../../../docs/scenario-formalization.md). Сейчас здесь только контракты
(`contracts.py`):

| Класс | Что задаёт |
|---|---|
| `Scenario` | Нарратив, источники, горизонт $H$, ограничения, движущие шоки, надбавки |
| `Constraint` | $\text{low}\le\sum w y_{i,t}\le\text{high}$ по списку слагаемых `terms`; при `low == high` значение точное |
| `Term` | Переменная, месяц $1\dots H$, ненулевой вес |
| `Overlay` | Надбавка $\Delta$ к драйверу в месяцы `start..end` с причиной и источниками |

Границы ограничений — в шкале модели $y=g(X)$: для ставки проценты, для курса $100\ln X$.
Имена переменных и шоков сверяет с реестром `mst.macro.registry.Registry.check`.

Хранение, проверка и утверждение сценариев, инструмент MCP `scenario` — шаг 7
[плана](../../../PLAN.md).
