# Исходный код MacroStress

Каталог содержит Python-пакет `mst`, который превращает описание события в условный прогноз показателей и стоимости портфеля. Условный прогноз — распределение будущих значений при заданном событии; портфель — набор позиций, например акций и облигаций, стоимость которых рассчитывается на общих траекториях экономики.

Имя устанавливаемого дистрибутива — `macrostress`, а имя для импорта в Python — `mst`. Раскладка исходников отдельно от корня проекта задана сборщиком `uv_build` в [pyproject.toml](<../pyproject.toml>); такое разделение помогает проверять установленный пакет, а не случайно импортировать файлы из корня.

## Как начать работу с кодом

Из корня репозитория установите окружение и откройте справку сервера:

```powershell
uv sync
uv run python -m mst.mcp --help
```

Команда `uv sync` устанавливает пакет и зависимости проекта, а справка перечисляет параметры запуска без расчёта сценария. Обзор ответственности пакетов находится в [карте mst](<mst/README.md>); порядок проверки изменений — в [руководстве к тестам](<../tests/README.md>).

Для использования системы через агента достаточно [основного руководства](<../README.md>). Для изменения расчётной логики начните с [архитектуры](<../docs/concept/architecture.md>) и контракта соответствующего пакета: модель экономики, модель показателя объекта и модель стоимости позиции выполняют разные задачи, поэтому изменение одной модели не требует переписывать остальные.
