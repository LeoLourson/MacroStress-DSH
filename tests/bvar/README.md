# Проверки макромодели BVAR

Набор проверяет плагин `bvar.sv` — байесовскую векторную авторегрессию, которая связывает показатели экономики с их прошлым и допускает изменение разброса случайных возмущений. Искусственная панель с известными коэффициентами помогает проверить восстановление параметров; такие проверки не доказывают, что модель описывает любую реальную экономику.

## Запуск и разделение проверок

Из корня репозитория можно проверить быстрые операции отдельно от оценки:

```powershell
.venv\Scripts\python.exe -m pytest tests/bvar -q -m "not slow"
.venv\Scripts\python.exe -m pytest tests/bvar -q
```

Полный набор включает тесты с маркером `slow`, потому что они выполняют случайную оценку модели. Изменение алгоритма оценки, идентификации или построения условного прогноза требует полного набора; быстрая проверка формы массива такого изменения не покрывает.

## Какие свойства закреплены

[Генератор simulated.py](<simulated.py>) строит историю из известных параметров, а [test_estimate.py](<test_estimate.py>) сравнивает восстановленные интервалы с истиной. Тесты проверяют запрет российских лагов в глобальных уравнениях, повтор результата по одному `seed`, восстановление пропусков, меняющийся разброс и скачки. `seed` — начальное значение генератора случайных чисел, которое фиксирует последовательность случайных входов.

| Проверка | Где искать основание |
| --- | --- |
| Шаги оценки разброса | [test_sv.py](<test_sv.py>) сравнивает распределения и путь логарифма дисперсии с известными входами. |
| Идентификация шоков | [test_identify.py](<test_identify.py>) проверяет знаки откликов, повороты и отбрасывание неустойчивых оценок. |
| Таблица знаков | [test_signs.py](<test_signs.py>) сверяет имена переменных, направления и ограничения долей шоков. |
| Условный прогноз | [test_forecast.py](<test_forecast.py>) проверяет точные и интервальные ограничения и закон против аналитического случая. |
| Начальные предположения | [test_prior.py](<test_prior.py>) проверяет дополнительные строки регрессии и их действие на сумму лагов. |
| Оценка изменений вместо уровней | [test_differences.py](<test_differences.py>) проверяет накопление изменений, дрейф и специальные столбцы скачков. |
| Граница наблюдаемой величины | [test_bounds.py](<test_bounds.py>) различает скрытое модельное значение и значение после нижней границы. |
| Размер нужных возмущений | [test_driving.py](<test_driving.py>) проверяет диагностику далёкого условия. |

Шок здесь означает случайное возмущение модели, а идентификация — выбор его экономического направления по ограничениям. Успех проверки знаков подтверждает исполнение записанных ограничений; экономическое прочтение шока требует отдельного основания.

[test_interventions.py](<test_interventions.py>) проверяет, что форма по умолчанию учитывает установку или сдвиг ровно один раз. [test_structural.py](<test_structural.py>) проверяет рекурсивную форму: замена значения внутри модели может изменить последующие значения, тогда как форма по умолчанию меняет только назначенные координаты своего уровня. Различие форм должно сохраняться и при сохранении версии.

Описание метода находится в [документации плагина](<../../src/mst/plugins/bvar/README.md>), а общие правила панелей и версий — в [tests/macro](<../macro/README.md>). Проверки покрытия интервалов относятся к выбранным искусственным моделям и допускам тестов; историческую точность нужно измерять отдельным набором эпизодов.
