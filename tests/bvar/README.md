# tests/bvar

Тесты плагина `mst.plugins.bvar` — референсной макромодели `bvar.sv`. Модель проверяется на
панели, сгенерированной из известных параметров (`simulated.py`): интервалы должны покрывать
истинные значения с заявленной частотой. `test_estimate.py`, `test_forecast.py` и
`test_identify.py` гоняют сэмплер, помечены `slow` и идут минуты.

| Файл | Что проверяет |
|---|---|
| `simulated.py` | Генератор панели и общие фикстуры |
| `test_estimate.py` | Покрытие истинных коэффициентов, блочная экзогенность, побитный повтор, розыгрыш пропусков, стохастическая волатильность |
| `test_sv.py` | Шаги Гиббса волатильности: смесь, степени свободы, путь логдисперсий |
| `test_identify.py` | Каждый оставленный розыгрыш выполняет знаки, повороты равномерны, неидентифицируемые отброшены |
| `test_forecast.py` | Точные и интервальные ограничения, побитный повтор, недопустимые сценарии, закон условий против аналитического значения, кандидаты пути волатильности |
| `test_signs.py` | Таблица шоков: согласованность с реестром переменных, знаки, уникальность |
