# tests/plugins

Тесты реестра плагинов, конформанс-проверки и команды `python -m mst.plugin`. Плагины для
проверок объявляются в тесте (`fakes.py`) или создаются во временном каталоге.

| Файл | Что проверяет |
|---|---|
| `fakes.py` | Модель, демо-кейс и объявление плагина для конформанс-проверок |
| `test_discovery.py` | Обнаружение пакетов `mst.plugins.<id>`, проверки объявлений вместе, дубликат id, чужое пространство имён метрик, несовместимый диапазон SDK, каталог моделей из реестра |
| `test_conformance.py` | `check_plugin` на объявлениях и демо-расчёте: ошибка в демо, недетерминированный результат, позиция, которая должна считаться, но не посчиталась |
| `test_boundary.py` | Ядро не знает конкретных типов актива: `mst.engine` не импортирует пакеты плагинов и не называет их идентификаторы |
| `test_cli.py` | `new` создаёт пакет, который проходит `check`, `demo-run` печатает квантили, сломанный пакет отклоняется с именем проблемы |
