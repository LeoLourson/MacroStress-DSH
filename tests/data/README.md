# Проверки загрузки и хранения истории

Набор проверяет `mst.data`: разбор ответов источников, перевод дневных значений в месячные и хранение опубликованных версий. Версия значения фиксирует, какой показатель был доступен в конкретный день; без версий исторический расчёт мог бы использовать поздний пересмотр. Сетевые ответы заданы тестами, поэтому доступность сайтов остаётся за пределами набора.

## Как запустить и выбрать проверку

Команда из корня репозитория проверяет весь слой данных:

```powershell
.venv\Scripts\python.exe -m pytest tests/data -q
```

Если изменён один загрузчик, начните с его файла, затем проверьте хранилище и цикл обновления. Такой порядок помогает отличить ошибку разбора ответа от ошибки датировки или записи, хотя итоговая проверка должна включать весь изменённый путь.

## Хранилище и обновление

[test_store.py](<test_store.py>) проверяет запись, чтение и отбор `as_of`, который выбирает последнюю публикацию не позже заданного дня. Тесты различают первую загрузку, пересмотр и признак `approximate`, означающий приблизительную дату публикации. Проверка идентификатора запрещает выход пути ряда за корень хранилища.

[test_update.py](<test_update.py>) проверяет, что повторная загрузка не добавляет одинаковые строки и ошибка одного ряда не теряет результаты остальных. [test_sources.py](<test_sources.py>) проверяет чтение и добавление объявления источника, занятые имена и связь встроенных источников с реестром переменных. [test_cli_client.py](<test_cli_client.py>) проверяет сертификаты всех хостов и применение дополнительных корней только к домену Росстата.

## Загрузчики

| Источник | Файл и поведение |
| --- | --- |
| FRED, база экономических рядов | [test_fred.py](<test_fred.py>) проверяет месячное усреднение, пропуски и отказ без ключа доступа. |
| Банк России | [test_cbr.py](<test_cbr.py>) проверяет ставку, RUONIA, курсы на одну единицу и кривую доходности. |
| Банковская статистика | [test_cbr_stats.py](<test_cbr_stats.py>) сравнивает обработку сервиса и архивных таблиц кредита, ипотеки и просрочки. |
| Московская биржа | [test_moex.py](<test_moex.py>) проверяет страницы индексов, режимы торгов и дробление акций. |
| Разница доходностей | [test_spread.py](<test_spread.py>) проверяет интерполяцию кривой, соединение истории и пропущенные дни. |
| Росстат | [test_rosstat.py](<test_rosstat.py>) проверяет выбор книги, сцепление приростов и таблицы цен жилья. |

RUONIA — показатель стоимости однодневного рублёвого заимствования; кривая доходности связывает ставку и срок облигации. Спред — разница доходности бумаги и опорной кривой. Определения нужны для выбора проверки, а экономическую интерпретацию конкретного ряда задаёт его источник.

Контракт хранения описан в [mst.data](<../../src/mst/data/README.md>). Если источник изменил формат, успешные тесты старого ответа не подтверждают совместимость с новым: сначала сохраните воспроизводимый пример изменившегося ответа по правилам проекта, затем уточните проверку.
