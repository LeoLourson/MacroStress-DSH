# tests/data

Тесты `mst.data`. HTTP-ответы источников подменяются, поэтому тесты проверяют разбор
форматов MOEX, ЦБ, Росстата и FRED, а не доступность сайтов.

| Файл | Что проверяет |
|---|---|
| `test_store.py` | Хранилище: запись и чтение, `as_of`, датировка первой загрузки и пересмотров, флаг `approximate`, id ряда не выходит за каталог |
| `test_update.py` | Цикл загрузки: новые строки пишутся один раз, ошибки — по ряду |
| `test_sources.py` | `sources.toml`: поиск, добавление таблицы, отказ на занятый id; каждый источник питает переменную реестра |
| `test_cli_client.py` | Сертификаты: проверяется каждый хост, корни Минцифры — только у `rosstat.gov.ru` |
| `test_fred.py` | FRED: месячные средние, пропуски, понятная ошибка без ключа |
| `test_cbr.py` | Ключевая ставка со ступенями до 2013 года, RUONIA, курсы на одну единицу, бескупонная кривая |
| `test_cbr_stats.py` | Кредит, ставка ипотеки, доля просрочки: сервис против архива, отказ на чужой или нечитаемой таблице |
| `test_moex.py` | Индексы постранично, режимы торгов и сплиты акций, остановка на необъявленном сплите |
| `test_spread.py` | Интерполяция кривой, спред индекса к кривой со сшивкой, пропуск дней |
| `test_rosstat.py` | Поиск книги по шаблону, сцепка приростов, разделы «Краткосрочных показателей», цены жилья по годам и кварталам |
