# tests/portfolio

Тесты `mst.portfolio` и расчёта портфеля. Пути, версии моделей и реестр драйверов собраны в
тесте, поэтому ожидаемые потери считаются по тем же формулам, что и в моделях позиций.

| Файл | Что проверяет |
|---|---|
| `conftest.py` | Позиции сохранённого портфеля для проверок |
| `test_spec.py` | Портфель — имя, базовая валюта и позиции; повтор id позиции и база не в рублях отклоняются |
| `test_tool.py` | `save`, `get`, `list`, `delete` и `check`: каждая причина отказа по имени, `exposure` по панели макроверсии |
| `test_report.py` | Потери P5/P50/P95 и ES95 по сумме внутри розыгрыша, исключённая позиция с причиной, покрытие и неизмеримая стоимость, статусы `ok`/`needs_review`/`incomplete`, цена сценария и её отсутствие без условий |
| `test_run.py` | `mst.runs` по портфелю: отчёт рядом с позициями, повтор расчёта с тем же сидом даёт те же числа, что сказано о позиции без расчёта |
