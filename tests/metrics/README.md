# Проверки метрик качества прогноза

Набор проверяет, как `mst.metrics` сравнивает распределение прогноза с историческим фактом и принимает решение о версии модели. Ячейка проверки — сочетание эпизода, месяца горизонта и величины. Искусственные модели с известным смещением помогают проверить, что верная и намеренно неверная модели получают ожидаемо разные оценки; они не доказывают точность установленной рабочей версии.

## Запуск

Из корня репозитория выполните набор метрик:

```powershell
.venv\Scripts\python.exe -m pytest tests/metrics -q
```

[simulated.py](<simulated.py>) задаёт тестовые макро- и сателлитную модели, чтобы проверить исторический расчёт целиком без длительной оценки экономической модели. Для изменения формулы отдельной метрики начните с её файла, затем проверьте агрегирование и полный отчёт.

## Что означают проверяемые оценки

CRPS — непрерывная ранговая вероятностная оценка: мера несовпадения прогнозного распределения с наблюдаемым значением, где меньшее число лучше. PIT — положение факта внутри прогнозного распределения; при верном распределении последовательность таких положений должна быть равномерной. ES95 — средняя потеря в худших 5 % распределения; её проверка относится к хвосту потерь портфеля.

Правильной формулы ячейки недостаточно: неравный вес величин или неверный интервал может изменить решение даже при верных отдельных оценках.

## Карта проверок

| Предмет | Файл и проверяемое поведение |
| --- | --- |
| Оценки ячеек | [test_cells.py](<test_cells.py>) сравнивает CRPS с аналитическим случаем, проверяет PIT, типичное движение, пропуски и эталонные прогнозы. |
| Объединение результатов | [test_aggregate.py](<test_aggregate.py>) проверяет равный вес величин, горизонты и вклад каждого эпизода. |
| Решение о версии | [test_decision.py](<test_decision.py>) проверяет допуск и сравнение разности с двумя стандартными ошибками. |
| Исторические эпизоды | [test_backtest.py](<test_backtest.py>) проверяет даты, сценарии, кэш версий, исключение заданных ячеек и отчёты. |
| Сетка дат | [test_rolling.py](<test_rolling.py>) сравнивает верную и смещённую модели, половины истории и пропуски дат. |
| Сравнение с эталоном | [test_quality.py](<test_quality.py>) проверяет относительный CRPS, блочные интервалы и условное случайное блуждание. |
| Зависимость вкладов | [test_wild.py](<test_wild.py>) проверяет воспроизводимость весов и интервалы при тяжёлых вкладах. |
| Хвост портфеля | [test_es.py](<test_es.py>) проверяет ES95, усечение, месяцы фактов и исключение нерассчитанных позиций. |
| Параметры команд | [test_cli.py](<test_cli.py>) требует явный план эпизодов и проверяет независимость хеша от расположения плана. |

Блочный интервал повторно выбирает соседние даты вместе, потому что пересекающиеся горизонты дают зависимые ошибки. Отдельные проверки следят, чтобы версия использовала публикации только до даты эпизода и сохраняла конфигурацию, влияющую на результат.

Методические определения находятся в [mst.metrics](<../../src/mst/metrics/README.md>) и [общей схеме](<../../docs/concept/formalization.md>). Число успешно проверенных искусственных случаев не служит заявлением о покрытии хвоста на реальных кризисах; для такого вывода нужен исторический отчёт с названными эпизодами и ограничениями.
