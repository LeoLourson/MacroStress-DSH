# tests/metrics

Тесты каркаса качества `mst.metrics`.

| Файл | Что проверяет |
|---|---|
| `simulated.py` | Фейковые макро- и сателлитная модели, быстрые настолько, что раннер гоняется целиком |
| `test_cells.py` | CRPS против аналитики нормального распределения, PIT, типичное движение, баллы ячеек, бутстрэп, правила допуска, эталоны |
| `test_backtest.py` | Раннер: ячейки эпизодов, кэш версий по состоянию данных, неизвестный шок и эпизод вне манифеста, `--details`, драйверы с наивным прогнозом, конфиг эпизодов согласован с шоками BVAR |
