# Проверки иерархической сателлитной модели

Набор проверяет `hier.gibbs` — модель, которая строит показатели объектов по их прошлому и более общим входам. Иерархия связывает параметры компании, отрасли и общего объекта: если собственной истории мало, модель может использовать параметры родителя. Генератор [simulated.py](<../drivers/simulated.py>) задаёт дерево и известные коэффициенты, чтобы проверка восстановления имела независимую истину.

## Запуск

Из корня репозитория выполните набор модели:

```powershell
.venv\Scripts\python.exe -m pytest tests/hier -q
```

Если меняется только сохранение законченной оценки, начните с [test_checkpoints.py](<test_checkpoints.py>), а для изменения формулы или пути нужен весь набор. Само создание каталога точек сохранения не доказывает возобновление: тест повторной оценки проверяет, что модель действительно читает готовую часть.

## Уравнения, проверки и пути

[test_satellite.py](<test_satellite.py>) проверяет покрытие известных коэффициентов, заимствование параметров и прогноз вне обучающего окна. Драйвер — показатель объекта; обслуживаемым считается драйвер, который версия разрешает рассчитывать по сохранённым проверкам. Если собственное уравнение не проходит проверку, тесты различают допустимое использование родителя и отказ, когда родитель тоже не подходит.

Набор проверяет сохранение версии и отказ изменённого содержимого, корреляционную матрицу остатков, передачу общих случайных остатков платформы и повтор путей по одному `seed`. `seed` фиксирует последовательность случайных входов. Старое последнее наблюдение нужно довести до начального месяца пути; квартальная история и пропущенные месяцы не должны молча стать месячными нулями.

[test_differences.py](<test_differences.py>) проверяет оценку изменений вместо уровней, накопление изменений в цену и действие вмешательства без повторного накопления. [test_credit_channel.py](<test_credit_channel.py>) сравнивает модель, читающую спред, с моделью без такого входа: изменение спреда должно достигать цены только через объявленную зависимость. [test_constant_spreads.py](<test_constant_spreads.py>) проверяет специальное поведение величин с фиксируемым спредом.

В [test_satellite.py](<test_satellite.py>) отдельные случаи проверяют диапазон обучения, чтение публикаций только до даты расчёта и перенос установленных значений внутри групп путей. Группа объединяет пути с общими параметрами и реализацией вмешательства; использование этих групп не должно менять другие ячейки.

Документация алгоритма находится в [плагине hier](<../../src/mst/plugins/hier/README.md>), а сборку нескольких моделей и уровней проверяет [tests/drivers](<../drivers/README.md>). Восстановление параметров искусственной модели не заменяет проверку реальных драйверов на исторических эпизодах.
