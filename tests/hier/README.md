# tests/hier

Тесты плагина `mst.plugins.hier` — референсной сателлитной модели `hier.gibbs`. Модель
проверяется на дереве объектов, сгенерированном из известных параметров
([../drivers/simulated.py](../drivers/simulated.py)).

| Файл | Что проверяет |
|---|---|
| `test_satellite.py` | Покрытие истинных коэффициентов, объект без истории берёт параметры сверху, проверка вне выборки, версия-бандл загружается как сохранена, пути с воздействиями, отстающий драйвер доводится до $t=0$, квартальные и взрывные драйверы, побитный повтор |
