# tests/corpus

Тесты `mst.corpus`. Сеть подменяется: ответы источников и страницы задаются в тесте, поэтому
проверяются разбор форматов, конвертация и индекс, а не доступность сайтов.

| Файл | Что проверяет |
|---|---|
| `pdfs.py` | Минимальный текстовый PDF, собранный вручную: один шрифт, строка на строку |
| `test_manifest.py` | Манифест читается и сохраняется байт в байт, издания разворачиваются в файлы и пути, адрес задаётся ссылкой или страницей с шаблоном, чужое издание отклоняется |
| `test_fetch.py` | Ссылки страницы абсолютные и с текстом, `page` + `match` берёт первую подходящую, `fetch` скачивает один раз и пишет `downloads.json` |
| `test_convert.py` | Склейка строк и переносов, выброс колонтитулов и номеров страниц, PDF в Markdown с шапкой и метками страниц, конец года при неизвестном дне, HTML с заголовками, абзацами и таблицами |
| `test_series.py` | Строки BIS из SDMX CSV, деноминация рублей только при заметном скачке, прирост индекса год к году |
| `test_episodes.py` | Окно от трёх месяцев до `start` до двенадцати после, движение и восстановление от последнего значения перед `start`, карточка сохраняет написанные разделы, фактор без данных остаётся `unmeasured`, `series.toml` называет только известные ряды |
| `test_index.py` | Нумерация разделов с страницами и путями заголовков, длинный раздел режется с целыми таблицами, поиск скрывает фрагменты позже `as_of` и ранжирует по стемам, разметка вопросов и recall, векторы находят фрагмент без общих слов, переиспользуются и проверяются при загрузке, `state.json` называет день и число фрагментов |
