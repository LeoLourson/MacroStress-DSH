# Проверки корпуса источников

Набор проверяет, как `mst.corpus` получает документ, извлекает текст и находит фрагменты, доступные на выбранную дату. Корпус — собрание источников для обоснования сценариев; фрагмент — часть документа с адресом раздела или страницы. Тесты задают сетевые ответы заранее, поэтому проверяют обработку форматов, но не доступность внешних сайтов.

## Запуск

Из корня репозитория выполните тематический набор:

```powershell
.venv\Scripts\python.exe -m pytest tests/corpus -q
```

Для изменения фильтра публикаций можно начать с [test_index.py](<test_index.py>), однако полный набор нужен, если правка меняет путь от манифеста к индексу. Манифест хранит перечень документов и адресов; ошибка в нём может скрыть материал ещё до этапа поиска.

## Что проверяют файлы

| Этап | Проверка |
| --- | --- |
| Объявление источников | [test_manifest.py](<test_manifest.py>) читает и сохраняет манифест, разворачивает издания и отклоняет чужие ключи. |
| Получение оригиналов | [test_fetch.py](<test_fetch.py>) разрешает относительные ссылки, выбирает ссылку по шаблону и проверяет повторную загрузку. |
| Извлечение текста | [test_convert.py](<test_convert.py>) проверяет переносы, удаление колонтитулов, страницы PDF, заголовки и таблицы веб-страницы. |
| Ряды эпизодов | [test_series.py](<test_series.py>) разбирает табличный формат BIS и проверяет поправку деноминации и годовые изменения. |
| Карточки события | [test_episodes.py](<test_episodes.py>) проверяет базу, экстремум, восстановление и сохранение ручного текста. |
| Поисковый индекс | [test_index.py](<test_index.py>) проверяет разбиение, адреса, фильтр дат и повторное использование векторов текста. |
| Командная строка | [test_cli.py](<test_cli.py>) проверяет чтение набора вопросов по явно заданному пути. |

[pdfs.py](<pdfs.py>) создаёт минимальный PDF с текстовым слоем, чтобы результат извлечения не зависел от случайного внешнего документа. Карточка эпизода использует измерение изменения от значения перед началом события; отсутствие ряда должно дать отметку `unmeasured`, а не придуманное движение.

Векторное представление текста помогает найти близкий по смыслу фрагмент без совпадающих слов. Тесты проверяют техническое использование и сохранение таких векторов; качество ответов на вопросы измеряют отдельно по ожидаемым фрагментам. Метрика recall показывает долю вопросов, для которых ожидаемый фрагмент попал в выбранное число результатов, но не оценивает истинность экономического вывода автора сценария.

Контракты и последовательность подготовки описаны в [mst.corpus](<../../src/mst/corpus/README.md>). При изменении индекса сохраняйте различие даты публикации и даты скачивания: тестовый документ, полученный сегодня, может быть известен задолго до сегодняшнего дня.
