# tests/engine

Тесты `mst.engine` и встроенных моделей позиций. Входы задаются путями и реестром драйверов,
собранными в тесте, поэтому ожидаемое значение позиции считается прямо по формуле.

| Файл | Что проверяет |
|---|---|
| `fixed.py` | Пути, где каждый драйвер идёт от заданного значения к заданному: ожидаемое значение позиции считается в уме |
| `simulated.py` | Макроверсия и сателлиты из известных авторегрессий: те же величины, что читают модели позиций |
| `test_dispatch.py` | Драйвер находится по кодам позиции (`secid`, затем `inn`), позиция без драйвера не считается и называет код, неизвестный тип актива отклоняется с именем, `terms` проверяются по схеме, валюта без пути курса и макропеременная не в путях названы, результат неверной формы и повтор id позиции отклоняются |
| `test_models.py` | Акция равна отношению цены, иностранная акция — по курсу; облигация теряет дюрация × расширение спреда; кредит — LGD × прирост просрочки; депозит читает ту же модель; недвижимость следует цене; квантили упорядочены, хвост выходит за P95; пометки драйверов доходят до результата; те же входы дают те же числа |
| `test_run.py` | Статус набора — худший из статусов позиций, позиция без модели сохраняет стоимость, результаты идут в порядке позиций |
