# tests/macro

Тесты ядра `mst.macro`: реестр переменных, панель и хранилище версий. Оценку, идентификацию
и условный прогноз BVAR проверяет [../bvar](../bvar/); здесь — контракт уровня 0 и то, как
платформа хранит и читает версии.

| Файл | Что проверяет |
|---|---|
| `test_registry.py` | Реестр совпадает с таблицами формализации, преобразования, сезонные переменные, проверка имён сценария |
| `test_panel.py` | Сезонность, порядок блоков, данные на дату, начало панели |
| `test_version.py` | Обязательные ключи версии, диспетчеризация на плагин-оценщик (`meta["model"]`), панель версии, побитный повтор, `estimate_macro` публикует версию из стора |
| `test_model_tool.py` | Инструмент `model(kind="macro")`: список, описание, `model_id`, задачи на ресурсе `models`, `kind=catalog` |
