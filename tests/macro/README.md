# tests/macro

Тесты `mst.macro`. Модель проверяется на панели, сгенерированной из известных параметров
(`simulated.py`): интервалы должны покрывать истинные значения с заявленной частотой.
`test_estimate.py`, `test_forecast.py` и `test_identify.py` гоняют сэмплер и идут минуты;
их пропускают, если модель не менялась.

| Файл | Что проверяет |
|---|---|
| `simulated.py` | Генератор панели и общие фикстуры |
| `test_registry.py` | Реестр совпадает с таблицами формализации, преобразования, знаки шоков, проверка имён сценария |
| `test_panel.py` | Сезонность, порядок блоков, данные на дату, начало панели |
| `test_estimate.py` | Покрытие истинных коэффициентов, блочная экзогенность, побитный повтор, розыгрыш пропусков, стохастическая волатильность |
| `test_identify.py` | Каждый оставленный розыгрыш выполняет знаки, повороты равномерны, неидентифицируемые отброшены |
| `test_forecast.py` | Точные и интервальные ограничения, побитный повтор, недопустимые сценарии, усечённое нормальное, тяжесть против аналитического значения |
| `test_version.py` | Версия загружается как сохранена и отклоняется после правки |
| `test_backtest.py` | Эпизоды `backtest.toml` согласованы с реестром, дата расчёта, исключения, покрытие, доля взрывных розыгрышей |
| `test_model_tool.py` | Инструмент `model(kind="macro")`: список, описание, задачи на ресурсе `models` |
