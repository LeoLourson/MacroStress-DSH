# dsh/skills

Скиллы, которые плагин регистрирует в DSH. Каждый скилл — файл `*.md` с фронтматтером:

```markdown
---
name: macrostress-scenario
description: Как собрать сценарий из корпуса и проверить его тяжесть
whenToUse: необязательно; когда агенту брать этот скилл
---

Текст скилла.
```

`../index.js` читает все `*.md` этой папки по алфавиту и пропускает файлы без `name`,
`description` или текста. Сам README фронтматтера не имеет, поэтому скиллом не станет.

Сейчас скиллов нет: они пишутся на шаге 11 плана ([../../PLAN.md](../../PLAN.md)), когда
появятся сценарии и прогон.
