# dsh/skills

Скиллы, которые плагин регистрирует в DSH. Каждый скилл — файл `*.md` с фронтматтером:

```markdown
---
name: scenario-from-corpus
description: Как собрать сценарий из корпуса и проверить его цену
whenToUse: необязательно; когда агенту брать этот скилл
---

Текст скилла.
```

`../index.js` читает все `*.md` этой папки по алфавиту и пропускает файлы без `name`,
`description` или текста. Файлы README фронтматтера не имеют, поэтому скиллами не станут.
Сами скиллы написаны на английском: их читает модель, а английский текст тратит меньше токенов.

| Файл | О чём |
|---|---|
| `scenario-from-corpus.md` | Как перевести событие в сценарий $s=(N,m,O,D,\mathcal C)$ по корпусу: календарь, условия, воздействия, причины, метки, утверждение человеком |
| `run-report.md` | Как запустить расчёт и читать $P_5$/$P_{50}$/$P_{95}$, ES95, цену, покрытие и пометки |
| `drivers.md` | Как обновить каталог, оценить сателлиты и что значит «сателлит отвергнут» |

Проверка без запуска DSH — `node dsh/test/smoke.mjs`: он подставляет фейковый контекст,
регистрирует скиллы, строит пять строк раздела из временного `workspace.json`, проверяет
однострочный запасной вариант, перечитывание файла и снятие скиллов.
