# dsh/skills

Скиллы, которые плагин регистрирует в DSH. Каждый скилл — файл `*.md` с фронтматтером:

```markdown
---
name: macrostress-scenario
description: Как собрать сценарий из корпуса и проверить его тяжесть
whenToUse: необязательно; когда агенту брать этот скилл
---

Текст скилла.
```

`../index.js` читает все `*.md` этой папки по алфавиту и пропускает файлы без `name`,
`description` или текста. Сам README фронтматтера не имеет, поэтому скиллом не станет.

| Файл | О чём |
|---|---|
| `scenario-from-corpus.md` | Как искать фрагменты корпуса и собирать $N$, $C$, $D$, $O$; чем `save` отличается от `validate` |
| `run-report.md` | Как запустить прогон и читать $P_5$/$P_{50}$/$P_{95}$, ES95, $\delta$, покрытие и пометки |
| `drivers.md` | Как обновить каталог, оценить сателлиты и что значит «сателлит отвергнут» |

Проверка без запуска DSH — `node dsh/test/smoke.mjs`: он подставляет фейковый контекст,
регистрирует скиллы, строит раздел промпта из `workspace.json` и сверяет пять строк.
