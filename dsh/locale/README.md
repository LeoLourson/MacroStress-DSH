# Название и описание плагина в интерфейсе

Каталог локалей содержит строки карточки `dsh-macrostress` в DeepSeek Harness (DSH). Переводчик меняет читаемые значения `meta.title` и `meta.description`, сохраняя имена ключей: по ключам клиент находит название и описание. Русская версия находится в [русской локали](<ru.json>), английская — в [английской локали](<en.json>).

Строки карточки описывают подключение MacroStress, а не экономический результат расчёта. Они не переводят тексты инструментов Python-сервера или инструкции агенту; назначение интеграции объясняет [описание пакета](<../README.md>). Такой разрез оставляет интерфейсные подписи рядом, не смешивая их с документацией моделей.

[Манифест пакета](<../package.json>) экспортирует локали по шаблону `./locale/*.json`. Для нового языка добавляется JSON-файл с теми же ключами и переведёнными значениями. Наличие файла само по себе не подтверждает выбор языка установленным клиентом: отображение следует проверить в профиле с соответствующей локалью.

[Локальная проверка](<../test/smoke.mjs>) читает русскую и английскую карточки и требует непустые `meta.title` и `meta.description`. Новый язык нужно также включить в проверяемый набор, иначе ошибка его ключей останется вне проверки. Команда выполняется из корня репозитория:

```powershell
node dsh/test/smoke.mjs
```
