# Проверочные вопросы поиска

Вопросы, которые возникают при построении сценария. У каждого есть дата `as_of`, на которую он задан, необязательный фильтр `kind` и список правильных фрагментов `expected` (их `chunk_id` из `corpus/index/chunks.jsonl`). Метрика `msa-corpus eval` — recall@5: доля правильных фрагментов в первых пяти результатах, средняя по размеченным вопросам. Вопрос без `expected` в метрику не входит.

`expected` ссылается на `chunk_id` текущей нарезки: после повторного `convert` или изменения нарезки разметку надо сверить. Правильный фрагмент — тот, в тексте которого есть ответ; размечено по чтению фрагментов, а не по выдаче поиска.
