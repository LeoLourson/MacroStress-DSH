MacroStress рассчитывает, сколько портфель теряет при заданном макроэкономическом сценарии.
Аналитик или агент задаёт пути нескольких макропеременных (например, ключевая ставка 21 % на протяжении всего года)
и называет шоки, их вызвавшие. Макромодель, оценённая на истории, 
достраивает согласованные пути остальных переменных, сателлитные модели переводят
их в драйверы (цены акций, спреды облигаций, просрочку отраслей, цены жилья), а по драйверам
уже оценивается каждая позиция портфеля. На выходе распределение потерь с $P_5$, $P_{50}$,
$P_{95}$, ES95 и жёсткостью сценария $\delta$. Метод подробнее описан в
[docs/scenario-formalization.md](docs/scenario-formalization.md).

Сервер устроен как MCP, поэтому может работать с любым агентом: Codex, Cursor, Claude Code, DeepSeek Harness.
Для DSH есть плагин в `dsh/`: он регистрирует три скилла и добавляет в промпт агента снимок
workspace.

## Что умеет

| Часть | Что делает |
|---|---|
| Ряды | Загружает месячные ряды MOEX, Банка России, Росстата и FRED с датой публикации каждого значения |
| Макромодель | Оценивает BVAR со стохастической волатильностью, идентифицирует шоки знаками, строит условный прогноз, считает жёсткость сценария, проверяет модель на исторических эпизодах |
| Драйверы | Находит объекты величин, оценивает иерархические сателлиты, проверяет их вне выборки, строит пути драйверов |
| Сценарий | Хранит файл $(N, C, D, O)$, проверяет его и строит пути: условный прогноз и драйверы на тех же розыгрышах |
| Модели позиций | Акция, облигация, кредит, депозит, недвижимость |
| Прогон и отчёт | Считает позиции на путях сценария и выдаёт $P_5$, $P_{50}$, $P_{95}$, ES95 и $\delta$ |
| Расширения | Новый тип актива, макромодель или сателлит — плагин: `python -m mst.plugin new --kind position\|satellite\|macro`, проверка контракта, демо-расчёт |
| Скиллы DSH | Сценарий из корпуса, отчёт, драйверы; раздел системного промпта из `workspace.json` |

MCP-инструменты: `jobs`, `series`, `corpus`, `scenario`, `run`, `portfolio`, `model`.
Справочник по ним — [docs/tools.md](docs/tools.md).

## Установка

Нужны Python 3.12 или новее и [uv](https://docs.astral.sh/uv/).

```powershell
git clone https://github.com/LeoLourson/MacroStress-DSH
cd MacroStress-DSH
uv sync
uv run macrostress --workspace C:/data/macrostress
```

Сервер говорит по stdio и печатает только ошибки: он ждёт клиента. Подключение к Claude
Desktop, Cursor и любому другому MCP-клиенту — [docs/mcp.md](docs/mcp.md), к DSH —
[docs/install.md](docs/install.md).

## Первые шаги

После подключения сервера клиенту доступны семь инструментов. Длительные операции запускаются
задачами: инструмент сразу возвращает `job`, а ход работы виден через `jobs`.

1. `jobs(action="state")` — что лежит в workspace: версии моделей, индекс корпуса, число задач.
2. `series(action="update")` — загрузить все макроряды. Для FRED нужен ключ в переменной
   окружения `FRED_API_KEY`.
3. `jobs(action="status", id=...)` и `jobs(action="log", id=...)` — ждать конца задачи.
4. `model(kind="macro", action="estimate", as_of="2026-10-29")` — оценить макромодель
   (`bvar.sv`, она одна установлена; `model_id` назовёт другую) на данных, известных к этой
   дате. Получится версия с хешем в имени.
5. `series(action="update", quantity="share_price")` — найти объекты величины и загрузить их
   ряды; так же для `bond_spread`, `overdue_share`, `housing_price_primary`,
   `housing_price_secondary`.
6. `model(kind="satellites", action="estimate", version=<хеш макроверсии>)` — собрать
   бандл сателлитов этой макроверсии: каждая величина оценивается назначенной ей моделью
   (по умолчанию `hier.gibbs`; `assignment` назовёт другую).
7. `model(kind="satellites", action="describe", version=<хеш>)` — какие драйверы прошли
   проверку вне выборки и почему остальные отклонены.
8. `corpus(action="search", query=..., as_of=...)` — фрагменты корпуса, известные на дату;
   `corpus(action="index")` пересобирает индекс задачей.
9. `scenario(action="save", id=..., spec={...})` — сохранить сценарий;
   `scenario(action="validate", id=...)` — назвать всё, что мешает его посчитать.
10. `portfolio(action="save", id=..., spec={...})` — сохранить портфель;
    `portfolio(action="check", id=..., scenario=...)` — проверить его против сценария.
11. `run(action="start", scenario=..., portfolio=..., draws=..., seed=..., targets=...)` —
    запустить прогон; `run(action="result", id=...)` — прочитать условный прогноз целевых
    показателей ($P_5$/$P_{50}$/$P_{95}$ по месяцам) и отчёт портфеля с $\delta$ и
    покрытием.
12. `model(kind="macro", action="backtest", as_of=...)` — проверка на эпизодах: CRPS,
    калибровка и допуск моделей на исторических событиях (`mst.metrics`).

## Словарь

| Термин | Что это |
|---|---|
| Ряд | Временной ряд с датой публикации каждого значения (`series/<id>.csv`) |
| Источник | Загрузчик рядов одного вида (MOEX ISS, ЦБ, Росстат, FRED) |
| Макромодель | BVAR с идентификацией шоков; версия — файлы с хешем |
| Величина | Вид драйвера: цена акции, спред облигации, доля просрочки отрасли, цена жилья |
| Объект | То, у чего есть драйвер: бумага, эмитент, отрасль, регион; у него есть коды `secid`, `isin`, `inn`, `okved`, `okato` |
| Каталог | Находит все объекты величины у источника |
| Сателлит | Модель драйвера от макропеременных; версия сателлитов — файлы с хешем |
| Тип актива | Расширение: какие входы нужны позиции, как их найти, как оценить позицию на путях |
| Сценарий | Нарратив $N$, ограничения $C$, движущие шоки $D$, надбавки $O$, ссылки на фрагменты корпуса |
| Пути | $R$ розыгрышей на $H$ месяцев: макропеременные и драйверы в исходных единицах |
| Жёсткость | $\delta$ — расстояние Махаланобиса середин ограничений от безусловного прогноза; больше $\delta$ — менее вероятен сценарий |
| Прогон | Портфель × сценарий × версии × дата × сид; повтор даёт те же числа побитно |
