# ADR 0004: Атомарная запись повторяется, когда читатель держит файл на Windows

Дата: 2026-11-02
Статус: принято

## Контекст

Состояние везде пишется атомарно: черновик — файл или папка — готовится рядом с целью, и
`os.replace` ставит его на место. На POSIX переименование поверх файла, который читает
другой процесс, разрешено, и читатель держит старую версию. На Windows `os.replace`
бросает `PermissionError`, пока хоть один процесс держит цель открытой — а
`workspace.json` читается ровно так: плагин DSH, из собственного Node-процесса, читает
его при каждой пересборке секции промпта. Запись, попавшая в это окно, роняла весь вызов
инструмента.

## Решение

Все атомарные записи — `store.write_json` для плоских JSON-файлов состояния,
`versions.save` для папки версии, `SeriesStore.write` для ряда и загрузка документа корпуса
— переносят черновик через `store.replace`, который
повторяет `os.replace` несколько раз (шесть попыток с паузой 20 мс), прежде чем пропустить
`PermissionError` наружу. Читатель, дочитывающий файл, отпускает дескриптор внутри окна
повторов; держатель, не отпускающий никогда, получает ошибку как раньше, и черновик
убирается как раньше.

## Последствия

Запись состояния, совпавшая с чтением секции промпта, больше не роняет вызвавший её
вызов; худший случай — задержка примерно в десятую долю секунды. На POSIX повторы ничего
не меняют: первый же `os.replace` проходит. Блокировка читателя вместо этого — протокол
разделяемых advisory-блокировок между Python-сервером и Node-плагином — отвергнута: он
связывал бы два рантайма согласием о семантике блокировок ради окна, измеряемого
миллисекундами.

Окно рассчитано на редкое короткое чтение. Node-процесс, который читает файл без остановки,
пропускает лишь 5 % замен (49 из 955 без повторов), и шести попыток против него не хватает:
прошло 2 записи из 25. Читатель на Python в единичных случаях сам получает `PermissionError`
в момент замены (на 14 628 чтений); `read_json` не повторяет чтение, и такой вызов нужно
повторить. Держатель, который задерживает файл дольше 100 мс, например антивирус, по-прежнему
получает ошибку.
