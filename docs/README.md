# Документация

Описание системы для того, кто открывает её впервые. Читать по порядку: установка, устройство,
инструменты, метод.

| Файл | Вопрос, на который отвечает |
|---|---|
| [mcp.md](mcp.md) | Как подключить сервер к любому MCP-клиенту, провести первый сеанс и разобрать типовые ошибки |
| [install.md](install.md) | Как поставить Python-часть, подключить плагин к профилю DSH и проверить, что всё видно |
| [architecture.md](architecture.md) | Из каких пакетов состоит система, что лежит в workspace, как устроены версии моделей и задачи, что попадает в системный промпт |
| [tools.md](tools.md) | Какие есть MCP-инструменты и команды `python -m mst.*`, что они принимают и возвращают |
| [system-scheme.md](system-scheme.md) | Общая схема: уровни, сценарий $(N,D,C,O)$, условный прогноз, метрики качества — что система делает и в каком порядке |
| [scenario-formalization.md](scenario-formalization.md) | Как устроен метод: переменные, сценарий, макромодель, условный прогноз, жёсткость, драйверы, отчёт; что из этого делает код |
| [plugins.md](plugins.md) | Как добавить тип актива плагином: объявление, модель, демо-кейс, проверки |
| [platform.md](platform.md) | Контракты расчёта: позиция, пути, модель, диспетчер, реестр, прогон и отчёт |

Описание каждого пакета лежит в README его папки (`src/mst/*/README.md`), корпуса — в
[../corpus/README.md](../corpus/README.md), плагина DSH — в [../dsh/README.md](../dsh/README.md).
